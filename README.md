# Diabetic Retinopathy Detection

## Overview

This project presents a multimodal deep learning framework for Diabetic Retinopathy detection by combining retinal fundus images with patient clinical data. The model leverages Swin Transformer and Cross-Modal Attention mechanisms to improve disease classification and support early diagnosis of high-risk cases.

## Features

- Multimodal learning
- Swin Transformer architecture
- Cross-Modal Attention
- Automated DR classification
- Medical image analysis

## Dataset

- BRSET Dataset
- Fundus retinal images
- Clinical patient data

## Technologies Used

- Python
- PyTorch
- Swin Transformer
- OpenCV
- NumPy
- Scikit-learn

## Results

- Accuracy: 94.01%
- Recall: 79%
- Improved detection of Proliferative Diabetic Retinopathy
